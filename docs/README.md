# Documentazione di Creator Lift

Creator Lift stima quante vendite in più ha portato ogni collaborazione con un creator, comprese quelle senza codice sconto, per piccoli brand e-commerce italiani su Shopify. Gira solo sul computer di chi la usa.

| Documento | Per chi | Cosa contiene |
| --- | --- | --- |
| [Guida all'uso](guida-utente.md) | chi usa l'app o la mostra a un brand | installazione, avvio, le due pagine, come leggere i risultati, domande frequenti |
| [Formato dei file](formato-dati.md) | chi prepara i dati | export Shopify, file dei post, file delle promozioni, regole di lettura, avvisi ed errori |
| [Metodo e validazione](metodo-e-validazione.md) | chi deve fidarsi dei numeri | come funziona la stima, il giudizio, il ROI, i risultati dei test sui negozi simulati |
| [Privacy](privacy.md) | chi deve garantire che i dati non escano | impostazioni, controlli all'avvio, come è stato verificato, limiti |
| [Architettura e sviluppo](architettura.md) | chi lavora sul codice | moduli, flusso dei dati, funzioni principali, test, come estendere |
| [Registro dei lavori](registro-lavori.md) | chi vuole sapere cosa è stato fatto e perché | passi, decisioni, revisioni, cambiamenti che toccano la stima, cose da fare |

Avvio rapido:

```
pip install -r requirements.txt
streamlit run app.py
```
